# Conversation domain

Mandatory continuity and confidentiality instructions are in `src/policy.ts`. `src/demo-intake.ts` persists partial caller facts, confirmations and a server-only clinic binding, validates callback/device evidence, and owns immutable preview/real-test submissions. Model tools never read contacts or existing tickets. `src/fields.ts` validates NANP callbacks and explicit yes responses. PBX lifecycle adapters and production deployment remain pending.
